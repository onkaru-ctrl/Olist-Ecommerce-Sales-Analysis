# Olist Ecommerce Sales Analysis

## Project Overview
This project is an interactive Power BI dashboard developed using the Brazilian Olist E-Commerce dataset. The dashboard provides insights into sales performance, customer behavior, payment methods, product categories, and geographical sales distribution using interactive visualizations and filters.

---

## Dashboard Features
- KPI Cards for Total Sales, Orders, Customers, and AOV
- Monthly Sales Trend Analysis
- Top Product Categories by Sales
- Payment Method Analysis
- State-wise Sales Distribution Map
- Top 10 Products Analysis
- Interactive Slicers and Filters
- Professional Dark-Themed Dashboard Design

---

## Tools Used
- Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Data Modeling
- Data Visualization
- CSV Dataset

---

## Dataset
Dataset Used: Brazilian Olist E-Commerce Public Dataset

Source: Kaggle

The dataset contains information related to customers, orders, payments, products, sellers, and reviews from a real-world Brazilian e-commerce platform.

## Business Insights
- Credit Card is the most used payment method.
- Sao Paulo generated the highest sales.
- Health & Beauty is the top-selling product category.
- Sales showed significant growth during 2017–2018.
- Customer orders increased steadily over time.
